# Organizer

**Organizer** es una aplicación de escritorio para explorar, comparar, fusionar y respaldar carpetas, con verificación de integridad de archivos binarios.

## Características

- 🌳 **Visualización en árbol**: navegá la estructura completa de una carpeta de forma jerárquica, con tamaños, fechas de modificación y tipos de archivo.
- 🔍 **Comparación de carpetas**: compará dos (o más) carpetas y visualizá diferencias (archivos nuevos, eliminados, modificados o idénticos).
- 🔀 **Fusión de contenido**: combiná el contenido de varias carpetas en un destino único, con reglas configurables para resolver conflictos (sobrescribir, mantener más reciente, renombrar, omitir).
- 💾 **Respaldos (backups)**: generá copias de seguridad completas o incrementales de una carpeta, con historial de versiones.
- ✅ **Verificación de integridad**: calculá y compará checksums (MD5, SHA-1, SHA-256) de archivos binarios para detectar corrupción o cambios no deseados.
